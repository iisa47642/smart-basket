# Smart Basket

Сравнение стоимости продуктовой корзины по магазинам. React + Kotlin/Spring Boot + PostgreSQL.

Опубликованная версия: https://13-143-160-190.sslip.io/. Проверка развёртывания от 27.10.2026 описана в [DEPLOY.md](DEPLOY.md).

## Запуск

На Ubuntu/Debian: `sudo ./deploy.sh`. Он создаёт `.env`, собирает образы и запускает Docker Compose.
На компьютере с Docker: скопируйте `.env.example` в `.env`, задайте случайные пароли и выполните `docker compose up -d --build`.
Не используйте значения-заглушки из примера. Администратор создаётся при первом запуске; повторный запуск не меняет пароль существующего пользователя.

Откройте `/`. Каталог и сравнение доступны без входа. Раздел `/admin` позволяет администратору добавлять, исправлять и удалять цены по датам. Логин задаётся `ADMIN_USERNAME`, начальный пароль — `ADMIN_PASSWORD`. Пароль хранится в БД как BCrypt-хеш. Самостоятельная регистрация в этом этапе не предусмотрена.

Для локального запуска на другом порту задайте `HTTP_PORT=127.0.0.1:18080`. Полная инструкция по HTTPS, резервным копиям и восстановлению находится в [DEPLOY.md](DEPLOY.md).

## Проверки

`./gradlew test bootJar` — интеграционные HTTP-тесты с H2 в режиме PostgreSQL и сборка сервера.
`cd frontend && npm ci && npm run build && npm audit` — проверка TypeScript, сборка и аудит зависимостей.
Дополнительно миграции и сценарии приложения проверяются на PostgreSQL 16; H2 не заменяет эту проверку.

Демонстрационные цены создаются при первой инициализации пустой базы. Они не являются актуальными предложениями торговых сетей. Существующая база при обновлении автоматически не перезаполняется.

Миграции Flyway заменяют автоматическое изменение схемы Hibernate. Для существующей базы устанавливается baseline 0, затем выполняются V1 и V2. При дублях или некорректных данных миграция останавливается: строки автоматически не удаляются. Перед обновлением нужна резервная копия.
